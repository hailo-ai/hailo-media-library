================
AI Analytics API
================

Hailo AI Analytics is a comprehensive software framework designed to facilitate the development and deployment of AI-powered video analytics applications on Hailo-15 AI Vision Processor Units (VPUs). It provides a robust set of tools, libraries, and APIs that enable developers to build efficient, scalable, and production-ready video analytics pipelines.
The main components of Hailo AI Analytics include:

- HailoRT – A production-grade, scalable runtime environment that enables high-throughput AI inference on Hailo devices.

- Media Library AI Analytics API – A C++ API built on top of HailoRT, enabling developers to efficiently implement AI-powered video analytics functionality.

- Media Library AI Analytics API reference examples – Sample code demonstrating how to use the API to develop analytics applications.

- Reference pipelines and applications – Pre-built example pipelines and applications that can be used as reference implementations for building complete AI video analytics solutions. This section include descriptions for the AI Analytic API and reference code examples for it.
