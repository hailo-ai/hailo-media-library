Acronyms and Conventions
========================

.. list-table::
   :widths: auto
   :header-rows: 1

   * - Acronym
     - Description
   * - 1080p
     - High Definition resolution of 1920 x 1080 progressive video
   * - 720p
     - High Definition resolution of 1280 x 720 progressive video
   * - ACE
     - AXI Coherency Extensions
   * - AHB
     - Advanced High-performance Bus
   * - APB
     - Advanced Peripheral Bus
   * - API
     - Application Programming Interface
   * - AVC
     - Advanced Video Coding (aka H.264, MVC)
   * - AVX
     - Advanced Vector eXtensions
   * - AXI
     - Advanced eXtensible Interface
   * - bps
     - Bits Per Second
   * - CABAC
     - Context Adaptive Binary Arithmetic Coding, HEVC entropy coding method
   * - CB
     - Coding Block
   * - CBR
     - Constant BitRate
   * - CIF
     - Common Interchange Format (352 x 288 pixels)
   * - CIR
     - Cyclic Intra Refresh
   * - CODEC
     - COmpressor/DECompressor
   * - CPB
     - Coded Picture Buffer
   * - CTB
     - Coding Tree Block
   * - CTU
     - Coding Tree Unit
   * - CU
     - Coding Unit
   * - CVS
     - Coded Video Sequence
   * - DBF
     - DeBlocking Filter
   * - DC
     - Direct Current
   * - DPB
     - Decoded Picture Buffer
   * - DPCM
     - Differential Pulse Code Modulation
   * - DU
     - Decoding Unit
   * - EOS
     - End Of Sequence
   * - FMA
     - Fused Multiply Add
   * - fps
     - Frames Per Second
   * - GDR
     - Gradual Decoding Refresh
   * - GOP
     - Group Of Pictures
   * - GPU
     - Graphics Processing Unit
   * - HD
     - High Definition (HD=1980 pixels x1080 lines, progressive scan)
   * - HEVC
     - High Efficiency Video Coding, a video coding standard (JCT-VC) (aka H.265)
   * - HRD
     - Hypothetical Reference Decoder
   * - IDR
     - Instantaneous Decoder Refresh
   * - MAD
     - Mean Absolute Difference
   * - mbps
     - Mega (1000000) Bits Per Second
   * - MC
     - Motion Compensation
   * - MV
     - Motion Vector
   * - NAL
     - Network Abstraction Layer
   * - NALU
     - NAL Unit, the smallest decodable unit of a stream
   * - NLE
     - NonLinear Editing
   * - PAL
     - Phase Alternate Line (resolution 720 x 576 pixels)
   * - POC
     - Picture Order Count
   * - PPS
     - Picture Parameter Set
   * - PU
     - Prediction Unit
   * - QCIF
     - Quarter CIF (176 x 144 pixels)
   * - QVGA
     - Quarter Video Graphics Array (320 x 240 pixels)
   * - QP
     - Quantization Parameter
   * - QQVGA
     - Quarter QVGA (160 x 120 pixels)
   * - RC
     - Rate Control
   * - RGB
     - Red, Green, Blue color space representation
   * - ROI
     - Region Of Interest
   * - RPDCM
     - Residual DPCM
   * - RPS
     - Reference Picture Set
   * - SAD
     - Sum of Absolute Difference
   * - SAO
     - Sample Adaptive Offset
   * - SEI
     - Supplemental Enhancement Information
   * - SPS
     - Sequence Parameter Set
   * - sub-QCIF
     - Sub Quarter CIF video resolution (128 x 96 pixels)
   * - SXGA
     - Super eXtended Graphics Array (resolution 1280 x 1024 pixels)
   * - TU
     - Transform Unit
   * - UHD
     - Ultra High Definition (4K=3840 pixels x 2160 lines; 8K=7680 pixels x 4320 lines)
   * - VBR
     - Variable BitRate
   * - VGA
     - Video Graphics Array (resolution 640 x 480 pixels)
   * - VLC
     - Variable Length Coding
   * - VPS
     - Video Parameter Set
   * - VUI
     - Video Usability Information
   * - WCG
     - Wide Color Gamut
   * - WPP
     - Wavefront Parallel Processing
   * - YCbCr
     - Color space with one luma and two chroma components used for digital encoding
   * - VPS
     - Video Parameter Set
   * - | YUV
     - | Color space with one luma and two chroma component. Originally used for analog encoding,
       | currently often used for either digital or analog encoding.
