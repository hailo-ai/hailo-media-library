======================================
H.264 and H.265 Levels Reference Table
======================================

This table lists every defined H.264 (AVC) and H.265 (HEVC) level along with the maximum
resolution, frame rate, and bitrate each level supports. Use it together with the
:ref:`hailo_encoder` configuration to pick a level that matches your encoded
resolution and target bitrate.
